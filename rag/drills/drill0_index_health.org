#+TITLE: Drill 0 — Index Health & Separation

* Drill 0 — index health & separation

Poke the store before the named drills. Toy analog (the marginalization example): we
eyeballed =D ≈ I_3= — docs unit-norm AND mutually orthogonal (Gram =D·Dᵀ = I=),
eyeballable at 3×3. On a REAL store that literal target is impossible (490 vectors in
384-D can't be orthogonal; related chunks SHOULD be similar), so "healthy & well
separated" becomes a menu of statistics + one probe:

1. *integrity* — norms ~1, no zero/NaN, right count & dim, ids unique
2. *separation* — spread of pairwise cosines / effective rank (not a collapsed cone)
3. *near-dups* — mass of cosine>~0.95 pairs (the Drill-2 substrate)
4. *self-retrieval probe* — each passage, re-embedded AS A QUERY, returns itself
   (the label-free generalization of =D ≈ I=)

** Setup — pull the whole index

#+BEGIN_SRC jupyter-python :session llms :kernel llms_kernel :async yes :exports both
  import json, urllib.request
  import numpy as np

  # 6333 locally / 16333 tunneled port
  QDRANT, COLLECTION = "http://localhost:16333", "ep_committee_docs"

  def _post(path, body):
      req = urllib.request.Request(QDRANT + path, data=json.dumps(body).encode(),
                                   headers={"content-type": "application/json"})
      return json.load(urllib.request.urlopen(req))["result"]

  def fetch_all():
      points, offset = [], None
      while True:
          body = {"limit": 256, "with_vector": True, "with_payload": True}
          if offset is not None: body["offset"] = offset
          r = _post(f"/collections/{COLLECTION}/points/scroll", body)
          points += r["points"]
          offset = r.get("next_page_offset")
          if offset is None: break
      return points

  pts   = fetch_all()
  V     = np.array([p["vector"] for p in pts], dtype=np.float32)   # [N, 384], unit-norm
  ids   = [p["id"] for p in pts]                                   # qdrant point uuids
  cids  = [p["payload"]["citation_id"] for p in pts]
  texts = [p["payload"]["text"] for p in pts]
  print(f"pulled {V.shape[0]} vectors, dim {V.shape[1]}")

** Check 2 — separation & anisotropy (the "distinct directions" half)

#+BEGIN_SRC jupyter-python :session llms :kernel llms_kernel :async yes :exports both
  S  = V @ V.T                          # cosine matrix (V unit-norm)
  iu = np.triu_indices(V.shape[0], k=1) # unique off-diagonal pairs
  off = S[iu]
  p50, p90, p99 = np.percentile(off, [50, 90, 99])
  print(f"cosine       p50={p50:.3f}  p90={p90:.3f}  p99={p99:.3f}  mean={off.mean():.3f}  max={off.max():.3f}")
  print(f"anisotropy   ||mean(V)|| = {np.linalg.norm(V.mean(0)):.3f}   (0 isotropic -> 1 cone)")
  ev  = np.linalg.svd(V - V.mean(0), compute_uv=False) ** 2
  pr  = ev.sum() ** 2 / (ev ** 2).sum()
  d90 = int(np.searchsorted(np.cumsum(ev) / ev.sum(), 0.90)) + 1
  print(f"effective    participation ratio = {pr:.1f} / {V.shape[1]}   (90% var in {d90})")
#+END_SRC

** Check 4 — self-retrieval probe (the real "eyeball D ≈ I")   [WE BUILD THIS TOGETHER]

Design = option (b): re-embed each passage's =text= AS A QUERY (with the bge prefix) and
search the index — does it return its OWN point at rank 1? Tests integrity AND that the
query recipe lands on the passage manifold = the label-free Drill-1 detector. Once green,
we break it (drop the prefix) to preview Drill 1.

Setup — a self-contained query embedder (same recipe as the README =embed= walkthrough):

#+BEGIN_SRC jupyter-python :session llms :kernel llms_kernel :async yes :exports both
  import torch, torch.nn.functional as F
  from transformers import AutoTokenizer, AutoModel

  _M = "BAAI/bge-small-en-v1.5"
  _QPREFIX = "Represent this sentence for searching relevant passages:"
  _tok = AutoTokenizer.from_pretrained(_M)
  _model = AutoModel.from_pretrained(_M).eval()

  @torch.no_grad()
  def embed_query(text, prefix=_QPREFIX):        # prefix -> CLS -> L2 (queries only)
      enc = _tok([f"{prefix} {text}".strip()], padding=True, truncation=True,
                 max_length=512, return_tensors="pt")
      cls = _model(**enc).last_hidden_state[:, 0]
      return F.normalize(cls, p=2, dim=1)[0].numpy()

  print("embed_query ready:", embed_query(texts[0]).shape)
#+END_SRC

  # q(x): passage 0 re-embedded AS a query
  q = embed_query(texts[0])
  # d(z): it's own stored passage vector
  d = V[0]

  print(f"self cosine similarity (q, d) = {q @ d}")
  #print(f"{F.cosine_similarity(torch.tensor(q), torch.tensor(d), 0)}")

  sims = V @ q                                            # the toy's  scores = D @ q, now over all 490
  rank = int((sims > sims[0]).sum()) + 1                  # self is row 0 — how many chunks beat it?
  print("self rank    =", rank, "/", len(V))
